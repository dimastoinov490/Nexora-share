# Nexora Share

**Nexora Share** — локальный Wi-Fi файловый сервер для Android с современным веб-интерфейсом. Позволяет просматривать и скачивать файлы с внутренней памяти телефона через любой веб-браузер (на ПК, iPhone, macOS, Linux, планшетах) без использования сторонних облачных сервисов и без подключения к интернету.

---

## ✨ Возможности

- **Полная автономность:** Работает локально в домашней Wi-Fi сети или через точку доступа телефона.
- **Встроенный HTTP-сервер:** Высокопроизводительный сервер на базе NanoHTTPD, работающий в фоновом режиме (Foreground Service).
- **Потоковая передача видео (HTTP Range Requests):** Мгновенная перемотка и просмотр больших видеозаписей без предварительной полной загрузки в память.
- **Галерея фотографий:** Просмотр миниатюр, полноэкранный слайдер (Lightbox) с перелистыванием и скачиванием оригиналов без сжатия.
- **Видеотека:** Обложки видео, длительность, размер, встроенный HTML5 плеер и прямое скачивание.
- **Файловый проводник:** Просмотр папок внутренней памяти (`DCIM`, `Pictures`, `Movies`, `Download`, `Documents`, `Music`, `Recordings`), поиск и сортировка.
- **Безопасность:** Защита от Directory Traversal, ограничение доступа системными каталогами, только чтение и скачивание (без удалённого изменения или удаления).
- **Тёмная тема Nexora:** Фирменная тёмная палитра `#101114` с акцентным оранжевым свечением `#FF8A00`.

---

## 📱 Стек технологий

- **Android:** Kotlin, Jetpack Compose, Material 3, Coroutines, Flow.
- **HTTP Server:** NanoHTTPD 2.3.1 (встроен в приложение).
- **Web Interface:** HTML5, CSS3, Vanilla JavaScript (встроен в APK, не требует CDN).
- **Архитектура:** MVVM, Clean Architecture, Foreground Service с постоянным уведомлением.
- **Сборка:** Gradle 9.3.1, Java 17, Android SDK 36.

## 🚀 Сборка через GitHub Actions

В репозитории настроен автоматический CI-пайплайн `.github/workflows/build-apk.yml`.
При каждом коммите в ветку `main` или ручном запуске через `workflow_dispatch` собирается готовый `app-debug.apk` и публикуется в артефактах сборки с именем `Nexora-Share-APK`.

Для локальной сборки:
```bash
./gradlew assembleDebug
```
Готовый APK будет находиться по пути:
`app/build/outputs/apk/debug/app-debug.apk`
